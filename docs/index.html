    Where these prices come from

    Every price here is a total round-trip fare for one adult in economy, fetched live from Google Flights when a holiday is opened. It is the same data the Google Flights website shows you — the Open ↗ link on each row reruns the exact search a price came from, with the same dates, stop filter and currency.

    Source
    Google Flights, via its internal search endpoint

    These are indicative prices, not quotes. Fares move hour to hour, so treat a price as a current snapshot rather than a guarantee, and always confirm the real fare with the airline before booking.

    Google returns different inventory depending on where the request comes from. Prices here are queried from Singapore, so they reflect what a local traveller is quoted.

    Carrier and stop count describe the outbound journey. The price covers both directions; the return itinerary is not part of the data.
