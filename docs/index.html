Where these prices come from

Every price here is a total round-trip fare for one adult in economy, read from Google Flights once a day and recorded so the trend can be seen. It is the same data the Google Flights website shows you — the Open ↗ link on each row reruns the exact search the price came from, with the same dates, stop filter and currency.

Source
Google Flights, via its internal search endpoint
Collected
Once daily at 09:15 SGT by a GitHub Actions job
Holidays

Journey time
Outbound only, layovers included, timezone-corrected
History
Committed to the repository — every observation is auditable

These are indicative prices, not quotes. Fares move hour to hour and a daily snapshot cannot capture that, so treat a single point as weak evidence and the trend as the signal. Always confirm the real price with the airline before booking.

Google returns different inventory depending on where the request comes from, and the collector does not run in Singapore. Prices stay comparable to each other because every observation comes from the same place, but they can differ from what you see booking at home.

Carrier and stop count describe the outbound journey. The price covers both directions; the return itinerary is not part of the data.

Collection code, configuration and the full observation history are in the repository ↗.
