Where these prices come from

Every price here is a total round-trip fare for one adult in economy. The figures you see are fetched live when the page loads, and a daily job also records one observation per window so the trend can be charted. It is the same data the Google Flights website shows you — the Open ↗ link on each row reruns the exact search a price came from, with the same dates, stop filter and currency.

These are indicative prices, not quotes. Fares move hour to hour and a daily snapshot cannot capture that, so treat a single point as weak evidence and the trend as the signal. Always confirm the real price with the airline before booking.

Google returns different inventory depending on where the request comes from. Live prices are queried from Singapore, so they reflect what a local traveller is quoted. The recorded trend line is collected from a GitHub runner outside Singapore, so historical points can sit slightly off the live figure — they are consistent with each other, which is what makes the trend meaningful.

Carrier and stop count describe the outbound journey. The price covers both directions; the return itinerary is not part of the data.
